# 🔥 START HERE - Огоньки Дружбы 2.0

## 🚀 Quick Start (3 steps)

### 1️⃣ Get Bot Token
```
1. Open Telegram
2. Find @BotFather
3. Send /newbot
4. Copy your token
```

### 2️⃣ Setup
```bash
# Install dependencies
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Configure
./setup.sh
# Or manually: cp .env.example .env
```

### 3️⃣ Run
```bash
python main.py
```

That's it! Bot is running! 🎉
