# 🔥 Огоньки Дружбы 2.0 (Friendship Flames 2.0)

**Production-Ready Telegram Bot** — вирусный геймифицированный бот с механикой Snapchat Streaks + Tamagotchi + мощной реферальной системой.

---

## 🎯 Основные механики

### 1. Огоньки Дружбы (Friendship Flames)
- ✅ Двустороннее подтверждение для зажигания огонька
- 🎨 8 уровней цветов огоньков (от красного до радужного)
- ⏰ Напоминания перед гашением (4ч, 1ч, 30мин)
- 💔 Механика погасания с эмоциональным откликом
- ✨ Воскрешение огоньков за звёзды (120-350⭐)
- 🎉 Милестоны: 7, 14, 30, 50, 100, 200, 365+ дней

### 2. Серийчики (Tamagotchi Pets)
- 🥚 Вылупляются после 3 дней серии
- 🌟 5 уровней редкости: common → rare → epic → legendary → mythic
- 📊 Система прокачки с эволюциями
- 🍖 Кормление, поглаживание, игры
- 🎨 50+ предметов для кастомизации
- ❤️ Система настроения (счастливый → грустный → депрессия)

### 3. Вирусная реферальная система
- 🌳 3-5 уровней глубины
- 💰 Прогрессивные награды: 50→600+ искр
- 👑 Реферальные достижения (5, 10, 25, 50, 100 рефералов)
- ⭐ Бонусы за Telegram Premium (×2-×3)
- 🎁 Уникальные награды за милестоны

### 4. Экономика
- 🔥 **Искры** — основная валюта (фарм через активность)
- ⭐ **Звёзды** — премиум валюта (достижения, покупки)
- ⚡ **Энергия** — для мини-игр (восстановление)

### 5. Социальные механики
- 🎁 Система подарков (торт, букет, ракета, корона)
- 🏆 Глобальный лидерборд (по сериям, искрам, рефералам)
- 📋 Ежедневные и недельные квесты
- 🎮 Мини-игры (Ловец искр)
- 📱 Генерация и share историй

### 6. Удержание и вирусность
- 🌍 Мультиязычность (5 языков: EN, RU, ES, FR, DE)
- 🎭 Онбординг с выбором аватара и туториалом
- 📊 Анти-чит система (кулдауны, лимиты)
- 🔔 Система уведомлений и напоминаний
- 🎪 События и сезонные механики (готово к расширению)

## 🧪 Тестирование

### Тест реферальной системы (несколько аккаунтов)

1. **Основной аккаунт**:
   - Запустите бота: `/start`
   - Пройдите онбординг
   - Перейдите в Рефералы: `👥 Рефералы`
   - Скопируйте реферальную ссылку

2. **Тестовый аккаунт (используйте другое устройство или Telegram Desktop)**:
   - Перейдите по реферальной ссылке
   - Пройдите регистрацию
   - Проверьте, что основной аккаунт получил уведомление о новом реферале

3. **Проверка начислений**:
   - Основной аккаунт должен получить +50 🔥 искр за первого реферала
   - В профиле должно отобразиться: `Рефералов: 1`

### Тест огоньков

1. **Зажигание огонька**:
   - Аккаунт А: `🔥 Мои огоньки` → `🔥 Зажечь новый огонёк`
   - Введите @username аккаунта Б
   - Аккаунт Б: получит запрос → `✅ Принять`

2. **Продление серии**:
   - Любой аккаунт: нажмите `🔥 Продлить` на огоньке
   - Оба аккаунта получат уведомление
   - Счётчик дней увеличится: `День 2`

3. **Вылупление питомца**:
   - Продлите серию 3 раза (3 дня)
   - Получите уведомление: `🎉 ПИТОМЕЦ ВЫЛУПИЛСЯ! 🥚→🐣`

### Тест питомца

1. Перейдите в `🐣 Мои питомцы`
2. Выберите действие:
   - `🍖 Покормить` (–30🔥, +15-30 XP)
   - `🤗 Погладить` (бесплатно, улучшает настроение)
3. При достижении нужного XP → питомец повысит уровень
4. Каждый 5-й уровень → эволюция редкости

## 📊 Структура базы данных

### Таблицы:

1. **users** — пользователи (ID, nickname, avatar, язык, валюты, статистика)
2. **streaks** — огоньки между пользователями (дни, статус, жизни, pet_id)
3. **pets** — питомцы (тип, эмодзи, уровень, XP, редкость, предметы)
4. **flame_requests** — запросы на зажигание огоньков
5. **gifts** — отправленные подарки
6. **quests** — квесты (ежедневные, недельные)
7. **shop_items** — купленные предметы
8. **achievements** — достижения
9. **notifications** — уведомления

### Индексы для производительности:
- `idx_streaks_users` — быстрый поиск огоньков по user_id
- `idx_streaks_status` — фильтрация по статусу
- `idx_users_referrer` — реферальное дерево
- `idx_quests_user` — квесты пользователя

Добавьте в `handlers/shop.py`:

from aiogram.types import LabeledPrice, PreCheckoutQuery

@router.callback_query(F.data == "shop_buy_stars")
async def buy_stars_package(callback: CallbackQuery):
    prices = [LabeledPrice(label="100 ⭐ Stars", amount=100)]
    
    await callback.message.answer_invoice(
        title="100 Stars Package",
        description="Get 100 ⭐ stars for premium features!",
        payload="stars_100",
        provider_token="",  # Пусто для Telegram Stars
        currency="XTR",
        prices=prices
    )

@router.pre_checkout_query()
async def process_pre_checkout(pre_checkout_query: PreCheckoutQuery):
    await pre_checkout_query.answer(ok=True)

@router.message(F.successful_payment)
async def process_successful_payment(message: Message):
    user_id = message.from_user.id
    await update_user(user_id, stars=user_data['stars'] + 100)
    await message.answer("✅ 100 ⭐ stars added!")

## 🐛 Troubleshooting

### Bot не запускается

```bash
# Проверьте токен
cat .env | grep BOT_TOKEN

# Проверьте зависимости
pip list | grep aiogram

# Проверьте права на файл БД
ls -la friendship_flames.db
chmod 666 friendship_flames.db
```

### Ошибка "Database is locked"

```bash
# Убедитесь, что БД не открыта в другом процессе
lsof friendship_flames.db

# Или пересоздайте БД
rm friendship_flames.db
python main.py
```

### Не приходят уведомления

Проверьте, что пользователь не заблокировал бота:
```python
# В коде бот автоматически игнорирует ошибки отправки
# через try/except блоки
```

### Telegram API rate limits

При большом количестве пользователей используйте:
- Батчинг уведомлений (группировка)
- Очереди сообщений (Celery)
- Webhook mode для мгновенной обработки
